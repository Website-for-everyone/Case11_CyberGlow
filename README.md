# CyberGlow — Tokyo Midnight Neon Studio

Интерактивная веб-студия и Telegram-бот для кастомизации и заказа дизайнерских LED-неоновых вывесок.

## 🌟 Ключевой функционал

1. **Tokyo Midnight UI:** Глубокая неоновая эстетика в стиле ночного Токио (`#12072B`, `#00F0FF`, `#FF007F`, `#39FF14`).
2. **Интерактивный Ne-on Конструктор:**
   - Ввод текста вывески с живым рендерингом многослойного неонового свечения.
   - Выбор неоновых шрифтов: *Neon Monoline, Tokyo Cyber, Neon Script, Retro Glow*.
   - Палитра ярких неоновых цветов: Tokyo Cyan, Sakura Pink, Electric Lime, Ultraviolet, Sunset Amber, Hyper Red, Ice White.
   - Смена фоновых текстур стены: темный кирпич, сырой бетон, неоновый переулок Токио, карбоновая сетка, матовый акрил.
   - Эффект неонового мерцания (flicker) и регулировка интенсивности свечения.
3. **Генератор CSS-кода:** Генерация готового для вставки CSS `text-shadow` и `filter` кода с кнопкой копирования в буфер.
4. **Инженерно-ценовой калькулятор:**
   - Расчет длины неоновой трубки на основе геометрии букв (в см и метрах).
   - Расчет потребляемой электрической мощности в Ваттах (W) и подбор блока питания (12V).
   - Расчет итоговой стоимости изготовления (материалы, основа из акрила, блок питания, работа).
5. **Каталог готовых фигур:** Крылья ангела, Коктейльный бокал, Кибер-череп, Неоновое сердце, Самурайская катана, Чашка кофе.
6. **Telegram-бот (Aiogram 3.x):**
   - Инлайн-каталог популярных фигур с фотографиями и ценами.
   - Заказ индивидуального макета по фотографии или скетчу.
   - Валидация формата входящих файлов (JPG, PNG).
   - Автоматическая диспетчеризация заявок владельцу студии (@Idrisov_prod).

## 🚀 Запуск проекта

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск веб-приложения и API
```bash
python -m uvicorn backend.app:app --host 0.0.0.0 --port 3011 --reload
```
Веб-интерфейс доступен по адресу: `http://localhost:3011`

### 3. Запуск Telegram-бота
```bash
python -m bot.bot
```

### 4. Запуск тестов
```bash
pytest tests/ -v
```
